# MaydonBand — futbol maydonini band qilish (React + Vite)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ papkasiga yig'adi
```

- Maydonlar ma'lumoti: `src/data.js` (`FIELDS`)
- Buyurtmalar `localStorage`da saqlanadi: `src/OrdersContext.jsx`
- Sahifalar: `src/pages/`
